#Task-Tracker

Built by Sai Manu Gundala

A simple to-do app to add, complete and delete tasks.

**Live demo:** https://saimanu-gundala.github.io/task-tracker

## Features
- Add tasks
- Tap a task to mark it done
- Delete tasks
- Tasks are saved in the browser (localStorage), so they stay after refresh

## Tech
HTML, CSS, JavaScript

## How to run
Open `index.html` in any browser.
